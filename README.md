# DLH NEXUS

The world's most advanced AI model — combining frontier reasoning, coding, and creative capabilities into a single unified intelligence.

## Features

- **DLH NEXUS MODEL** — The most advanced AI model, combining multiple frontier models into one superior intelligence
- **Chat** — Streaming conversations with markdown support, code highlighting, and file attachments
- **Image Generation** — Create stunning images from text descriptions
- **DLH NEXUS BOT** — Autonomous AI agent for multi-step task execution
- **Connectors** — 10+ integrations including web search, code execution, translation, and more
- **Device Control** — Access camera, microphone, geolocation, screen share, clipboard, notifications, battery, and more
- **Responsive** — Auto-fits phones, tablets, and desktops
- **Black & White Design** — Clean, minimalist aesthetic inspired by aerospace engineering

## Tech Stack

- Vanilla HTML/CSS/JS (no framework overhead)
- Puter.js for AI model access
- Geist font family
- Fully responsive design

## Deployment

Deployed via Vercel, connected through GitHub.
